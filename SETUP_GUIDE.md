## ✅ ШАГ 2: Создание Telegram бота

### 2.1. Создайте бота
1. Откройте Telegram
2. Найдите [@BotFather](https://t.me/BotFather)
3. Отправьте: `/newbot`
4. Укажите имя: `Library Reminder`
5. Укажите username: `your_library_reminder_bot` (должен заканчиваться на `bot`)
6. **СОХРАНИТЕ ТОКЕН** вида: `1234567890:ABCdef...`

### 2.2. Получите Chat ID вашей мамы
**Вариант 1 (простой):**
1. Попросите маму найти бота по username и нажать Start
2. Откройте в браузере: `https://api.telegram.org/botВАШ_ТОКЕН/getUpdates`
3. Найдите `"chat":{"id": 123456789}` — это Chat ID

**Вариант 2 (через другого бота):**
1. Попросите маму найти [@userinfobot](https://t.me/userinfobot)
2. Она отправляет `/start`
3. Бот вернёт её Chat ID

**СОХРАНИТЕ:**
- `TELEGRAM_BOT_TOKEN`: ваш токен
- `TELEGRAM_CHAT_ID`: Chat ID мамы

## ✅ ШАГ 3: Локальное тестирование (необязательно, но рекомендуется)

Проверьте, что скрипт работает на вашем компьютере:

### 3.1. Установите переменные окружения

**В CMD:**
```cmd
set TELEGRAM_BOT_TOKEN=ваш_токен_от_BotFather
set TELEGRAM_CHAT_ID=chat_id_мамы
```

**Или в PowerShell:**
```powershell
$env:TELEGRAM_BOT_TOKEN="ваш_токен_от_BotFather"
$env:TELEGRAM_CHAT_ID="chat_id_мамы"
```

### 3.2. Запустите скрипт

```cmd
python send_message.py
```

**Ожидаемый результат:**
- Скрипт проверит, последний ли сегодня четверг месяца
- Если да — отправит сообщение маме
- Если нет — выведет сообщение и завершится без отправки

Проверьте Telegram — сообщение должно прийти маме (если сегодня последний четверг).

### 4.1. Создайте репозиторий
1. Зайдите на [github.com](https://github.com)
2. Нажмите **+** → **New repository**
3. Имя: `Telegram-Reminders`
4. Приватность: **Public** или **Private** (на ваш выбор)
5. **НЕ ДОБАВЛЯЙТЕ** README, .gitignore (они уже есть!)
6. Нажмите **Create repository**

### 4.2. Инициализируйте Git и загрузите код

Откройте терминал в папке проекта:

```cmd

git branch -M main

git push -u origin main
```

**Замените** `ВАШ_USERNAME` на ваше имя пользователя GitHub!

## ✅ ШАГ 5: Добавление секретов в GitHub

### 5.1. Откройте настройки репозитория
1. Зайдите в ваш репозиторий на GitHub
2. **Settings** (справа вверху)
3. **Secrets and variables** → **Actions**

### 5.2. Добавьте первый секрет
1. **New repository secret**
2. Name: `TELEGRAM_BOT_TOKEN`
3. Value: ваш токен от BotFather
4. **Add secret**

### 5.3. Добавьте второй секрет
1. **New repository secret**
2. Name: `TELEGRAM_CHAT_ID`
3. Value: Chat ID мамы
4. **Add secret**

**Проверьте:** Должно быть 2 секрета с правильными именами!

## ✅ ШАГ 6: Тестирование GitHub Actions

### 6.1. Запустите workflow вручную
1. Зайдите в ваш репозиторий
2. **Actions** (верхнее меню)
3. **Monthly Library Reminder** (слева)
4. **Run workflow** → **Run workflow** (зелёная кнопка)
5. Подождите ~30 секунд

### 6.2. Проверьте результат
1. Кликните на появившийся запуск workflow
2. Кликните на job **send-reminder**
3. Изучите логи — там будет вся информация:
   - Проверка даты
   - Попытка отправки (или пропуск)
   - Результат выполнения

**Что должно произойти:**
- ✅ Если сегодня **последний четверг** — сообщение придёт маме
- ℹ️ Если **не последний четверг** — в логах будет написано "Пропускаем отправку"

## ✅ ШАГ 7: Проверка сообщения мамы

### Если сегодня последний четверг:
1. Откройте Telegram
2. Найдите чат с вашим ботом
3. Попросите маму проверить её чат с ботом
4. Должно прийти: **"Сегодня в библиотеке санитарный день!"**

### Если не последний четверг:
- Дождитесь следующего последнего четверга месяца
- В 09:00 UTC (12:00 МСК) сообщение придёт автоматически
- Или запустите workflow вручную в нужный день

## 🆘 Что делать, если что-то не работает

### ❌ Workflow падает с ошибкой
**Проверьте:**
1. Секреты установлены правильно (Names без опечаток)
2. Токен бота валиден (BotFather не отозвал)
3. Chat ID правильный (попробуйте получить заново)

### ❌ Сообщение не приходит
**Проверьте:**
1. Мама нажала Start в чате с ботом?
2. Бот не заблокирован?
3. Логи GitHub Actions — там будет причина

### ❌ Ошибка "Chat not found"
**Решение:**
- Попросите маму найти бота и нажать `/start`
- Получите Chat ID заново через getUpdates
